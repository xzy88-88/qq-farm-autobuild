# 奶茶活动自动升级与制作

功能版本：`milk-tea-auto-v1`。

在「设置 → 自动控制 → 奶茶活动」分别开启「自动升级奶茶店铺」和「自动制作奶茶」，点击「保存自动控制」。开关按账号保存，现有账号默认关闭。

- 已登录账号在服务器后台每分钟检查一次，先尝试升级，再制作；关闭网页或电脑后继续运行。
- 升级依据服务器的实时资格和当前等级；未达到条件、未开业、活动结束或结算期间不操作。
- 制作只使用已解锁配方对应的未锁定普通果实，保留变异果实。协议以果实 UID 提交，因此每个选中的堆叠全部消耗，单轮最多处理 200 个堆叠。
- 提交前再次读取材料数量、锁定和变异状态；数量变化时取消本轮。自动与手动奶茶操作共用串行队列。
- 关闭开关、账号离线、登录会话变化或进入结算期后，尚未发送的请求会取消。已经发送给服务器的请求无法撤回。
- 失败后至少等一分钟再检查，连续失败逐步延长到最多十五分钟；不立即重复消耗操作。成功但刷新失败的升级会保留成功结果，下一轮再刷新。
- 奶茶页展示开关状态和最近检查结果，可用页面的刷新按钮获取最新状态。运行日志记录升级、制作杯数和失败原因。

不会自动开业、改名、雇佣、使用喇叭、购买、兑换或领取奖励。这些操作仍由用户自行决定。

发布时须同时检查上游 revision 与功能标记，不能只凭上游提交相同就跳过自定义补丁。候选镜像须通过测试、登录兼容检查和隔离启动后，才使用原备份及回退流程切换。
